# movie-recommender-system
Movie recommendation system on MovieLens: collaborative filtering with SVD matrix factorization and content-based filtering with TF-IDF tags and cosine similarity, implemented from scratch in NumPy

## Цель

По прошлым оценкам пользователя предсказать, какие фильмы ему понравятся:
- найти пользователей со схожими предпочтениями и предсказать оценки непросмотренных фильмов (коллаборативная фильтрация);
- рекомендовать фильмы, похожие по тегам на те, что пользователь оценил высоко (контентная фильтрация).

## Данные

[MovieLens 32M (GroupLens)](https://grouplens.org/datasets/movielens/32m/):
- `ratings.csv` — 32 000 204 оценки от 200 948 пользователей
- `movies.csv` — 87 585 фильмов с названиями и жанрами
- `tags.csv` — пользовательские теги

## Что сделано

### 1. Коллаборативная фильтрация (SVD)
1. **Фильтрация**: оставлены пользователи с ≥ 100 оценками и фильмы с ≥ 300 оценками, чтобы снизить разреженность. Для расчётов взята выборка из 100 000 строк.
2. **Разбиение на train/test**: 80/20.
3. **Матрица «пользователь × фильм»**: разреженность составила 96,49%. Пропуски заполнены средней оценкой пользователя.
4. **SVD**: матрица разложена через `np.linalg.svd` и восстановлена по первым k латентным факторам.
5. **Подбор k**: перебор k = 10…90 с оценкой RMSE на тестовой выборке.
6. **Рекомендации**: топ-N фильмов с наибольшей предсказанной оценкой, без фильмов, которые пользователь уже оценил.

### 2. Контентная фильтрация (TF-IDF + косинусное сходство)
1. Теги сгруппированы по фильмам, построена бинарная матрица частот (фильмы × теги).
2. Теги взвешены по IDF, получена матрица TF-IDF.
3. Посчитано попарное косинусное сходство фильмов.
4. Реализованы две функции:
   - `get_recommendations(movie_id)` возвращает фильмы, наиболее похожие на заданный;
   - `recommend_for_user(user_id)` усредняет сходство по фильмам, которые пользователь оценил на 4 и выше, и рекомендует непросмотренные.

## Результаты

| k (число факторов) | RMSE |
| ---: | ---: |
| 10 | 0,9220 |
| **20** | **0,9216** |
| 30 | 0,9248 |
| 50 | 0,9297 |
| 90 | 0,9392 |

Лучший результат: **RMSE ≈ 0,92 при k = 20** (шкала оценок 0,5–5). При большем числе факторов модель начинает подстраиваться под шум.

Пример контентной фильтрации: для *Toy Story (1995)* самые похожие фильмы — *The Little Mermaid* (сходство 0,65), *The Sword in the Stone* (0,40), *Ratatouille* (0,22).

## Ограничения и дальнейшие шаги

- Использована выборка из 100 тыс. оценок и 1 000 тегов, потому что плотная матрица и попарное сходство требуют много памяти. Чтобы обработать весь датасет, нужны разреженные матрицы (`scipy.sparse`, `TruncatedSVD`).
- Заполнение пропусков средним сдвигает предсказания к средней оценке пользователя. Как улучшение можно попробовать ALS или SVD со смещениями (например, библиотеку `surprise`).
- RMSE не оценивает качество ранжирования, для этого нужны Precision@K, Recall@K, NDCG.
- Следующий шаг: гибридная модель, объединяющая коллаборативные и контентные оценки.
